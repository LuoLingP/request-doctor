## 文档维护规则

1. 需求变更先改《软件需求规格说明》，再改设计与测试报告。
2. 任何度量项变化后重新生成《软件质量度量报告》与 `quality-report.json`。
3. 测试用例数量变化时，同步更新《软件测试报告》汇总表与 `RELEASE_CHECKLIST.md`。
4. 新增模块必须在《软件设计说明》第 2.2 节登记。
