# 软件质量度量报告

**产品名称**：dsh-request-doctor（请求急救员）
**版本**：0.11.0
**度量标准**：GB/T 45717-2025《信息技术 软件测量 软件质量测量 自动化的源代码质量测度》
**度量工具**：`tools/quality-measure.mjs`（本仓库自带，可复现）

---

## 1 度量方法

### 1.1 范围

度量范围为本插件自有的 JavaScript 源代码：`index.js` 与 `lib/*.js`。排除 `test/`、`tools/`、`node_modules/`，避免测试与工具代码影响产品代码的质量结论。

### 1.2 度量项

| 度量项 | 定义 | 计算方式 |
| --- | --- | --- |
| 注释密度 | 注释行占源代码行的比例 | 注释行 ÷ (总行 − 空行 − 注释行) × 100% |
| 重复率 | 重复逻辑行占比 | 归一化后（去字符串字面量差异）重复出现的逻辑行 ÷ 逻辑行总数 × 100% |
| 圈复杂度 | 函数的独立路径数 | 1 + 分支/循环/catch/逻辑运算符数；一个 `switch` 的全部臂计为 1 个决策 |
| 函数长度 | 单个函数的物理行数 | 函数自身的行，嵌套函数体不计入外层 |
| 文件长度 | 单个文件的物理行数 | 全文件行数 |

### 1.3 度量口径说明

- **嵌套函数独立计量**：组合根与工厂函数内部声明的闭包各自成为度量单位。若把内层代码计入外层，任何符合"组合优于继承"写法的代码都会被误判为超标。
- **`switch` 臂合并计量**：以运算符或类型标签为分支的 `switch` 是查表，不是判定树。逐个计数会惩罚表驱动写法，与度量意图相悖。
- **重复率只计逻辑行**：注释、`import`、纯标点行、对象字段声明与 `while ((match = ...))` 这类正则遍历惯用法不计入。这些行的重复反映的是语言与类型结构，不是复制粘贴。
